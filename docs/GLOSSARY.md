# GLOSSARY.md — Glosarium Istilah

Istilah domain konstruksi & PLTS yang dipakai di seluruh dokumen proyek ini.

| Istilah | Arti |
|---|---|
| **PLTS** | Pembangkit Listrik Tenaga Surya — proyek konstruksi yang jadi objek sistem ini |
| **RAB** | Rencana Anggaran Biaya — rencana total biaya proyek sebelum pekerjaan dimulai |
| **RAP** | Rencana Anggaran Pelaksanaan — versi RAB yang disesuaikan saat pelaksanaan (kadang dipakai bergantian dengan "realisasi") |
| **BOQ** | Bill of Quantity — daftar rinci volume pekerjaan/material dalam RAB |
| **AHSP** | Analisa Harga Satuan Pekerjaan — metode standar menghitung harga satuan suatu pekerjaan dari komponen material+upah+alat |
| **Realisasi / Actual** | Biaya yang benar-benar dikeluarkan di lapangan, dibandingkan dengan RAB |
| **Variance** | Selisih antara RAB dan realisasi, biasanya dalam persen |
| **Overbudget** | Kondisi realisasi melebihi RAB yang direncanakan |
| **S-curve (Kurva S)** | Grafik kumulatif progres/biaya rencana vs aktual dari waktu ke waktu, berbentuk huruf S |
| **Manpower** | Tenaga kerja — dalam sistem ini merujuk ke headcount tim per tahapan pekerjaan |
| **EVM** | Earned Value Management — metode mengukur performa biaya & jadwal proyek |
| **PV (Planned Value)** | Nilai anggaran yang direncanakan selesai pada suatu titik waktu |
| **EV (Earned Value)** | Nilai anggaran dari pekerjaan yang benar-benar sudah selesai |
| **AC (Actual Cost)** | Biaya aktual yang sudah dikeluarkan sampai titik waktu tertentu |
| **CPI (Cost Performance Index)** | `EV / AC` — di bawah 1 berarti proyek boros dari rencana |
| **SPI (Schedule Performance Index)** | `EV / PV` — di bawah 1 berarti proyek terlambat dari jadwal |
| **EAC (Estimate at Completion)** | Perkiraan total biaya akhir proyek berdasarkan performa saat ini |
| **Procurement** | Proses pengadaan/pembelian material dan jasa untuk proyek |
| **Vendor** | Pemasok material/jasa untuk proyek |
| **RAG (Retrieval-Augmented Generation)** | Teknik AI: mengambil data relevan dari database dulu, baru dikirim ke model AI sebagai konteks jawaban |
| **Embedding** | Representasi numerik dari teks yang dipakai untuk pencarian kemiripan makna (semantic search) |
| **9Router** | Gateway/proxy self-hosted yang meneruskan request AI dari backend ke provider LLM (di proyek ini: Claude) |
| **OCR** | Optical Character Recognition — ekstraksi teks/data dari gambar, dipakai di sini untuk baca nota/invoice lewat Claude vision |
